# Politique de confidentialité

Electrik ne collecte aucune donnée personnelle et n'envoie aucune statistique d'utilisation.

- Les projets, plans et logos restent sur l'ordinateur, dans les fichiers que l'utilisateur enregistre. La sauvegarde automatique est stockée localement (`%APPDATA%\Electrik`).
- La version téléchargée depuis GitHub ou winget vérifie au démarrage s'il existe une nouvelle version sur GitHub (`github.com/Coolbreeze88/electrik`). Cette requête ne contient aucune donnée du projet. La version Microsoft Store est mise à jour par le Store et ne fait pas cette vérification.

Contact : https://github.com/Coolbreeze88/electrik/issues
